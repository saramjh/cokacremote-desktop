ChatGPT setup

One human approval.
A visible connection.

After the MCP service is healthy, registration happens inside your own ChatGPT account—not through an automated browser action.

1

In the manager, verify the server, Cloudflare endpoint and OAuth status. Copy the HTTPS MCP endpoint.

2

On ChatGPT web, open Plugins and add a custom MCP server if your account or workspace permits it.

3

Enter the endpoint. Review available tools and permissions, then complete OAuth approval in the connection flow.

4

Test a low-risk read-only action first. If the Quick Tunnel hostname changes, update the connection.

Trust boundary

Visibility is a security feature.

This manager is designed for a powerful local MCP service. It should fail closed when a process owner is unknown, an authorization check fails, or an external operation's result is uncertain.

↳

No silent installation

Missing dependencies require your explicit approval. Existing healthy tools are reused.

⌁

No guessed connection state

Local health does not prove your ChatGPT plugin is connected. Check both ends.

⊘

No security shortcuts

macOS notarization and signed distribution matter. Never disable Gatekeeper to install software.
