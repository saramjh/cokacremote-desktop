Contact & support

Check the main FAQ and installation troubleshooting before reporting an issue.

Submit a support question

  1. Choose Open GitHub support form below. A GitHub account may be required.
  2. Describe the OS, app version, error text and safe reproduction steps. Do not include OAuth approval keys, access tokens, private hostnames or personal details.
  3. Press GitHub's Submit new issue button. A new issue detail page with an issue number is your actual submission confirmation; this static showcase cannot detect or verify an external issue submission on its own.

Open GitHub support form ↗

Response expectation: a first review is targeted within 3–5 business days when possible. This is a best-effort target, not a guaranteed service-level agreement; volunteer availability, triage and issue complexity can make it longer. GitHub issues show public replies and status.

After submitting

GitHub shows your created issue and its permanent URL. Save that URL, watch the issue for a reply, and use it for follow-up. Do not interpret returning to this website as proof of successful submission. Browse existing issues to check for duplicates.

Data-handling details are in this project's Privacy notice.
