Ways to use the connection manager

These are examples based on verified features and implementation tests, not third-party customer case studies or guaranteed outcomes.

1. Keep a healthy MCP connection running

Situation: You have an existing local MCP server and a Cloudflare Quick Tunnel. A status refresh should not break the route ChatGPT uses.

  1. Inspect the Local, Remote and OAuth indicators.
  2. Use verification and reuse rather than forcing a restart when both processes are healthy.
  3. If the Quick Tunnel endpoint changes, recheck the public URL and ChatGPT registration.

2. Approve prerequisite changes individually

Situation: A supported dependency such as Git or cloudflared is missing from the computer.

  1. Run the dependency inspection.
  2. Review the detected gaps and each proposed operation.
  3. Approve only the action you want. A fully unattended fresh-machine installation has not been verified.

3. Connect under your account's OAuth approval

Situation: You want to make an owner-operated local tool reachable from ChatGPT without handing an approval key to someone else.

  1. Verify server and tunnel and copy the current HTTPS URL ending in /mcp.
  2. Register the endpoint if your ChatGPT plan/workspace supports custom MCP.
  3. Review permissions, approve OAuth through the official interface, then test a read-only operation.
