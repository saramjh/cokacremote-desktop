Privacy & analytics choices

Updated 2026-10-23. This notice covers only the /cokacremote-desktop/ showcase and its static subpages. The independently hosted DevTestudinidae blog shares the domain but maintains a separate blog privacy policy.

Analytics: opt-in only

We use the existing DevTestudinidae Google Analytics 4 web stream (G-4DYFKSNFBG) to understand aggregate showcase page visits and clicks on its own download or contact buttons. Google may process IP-derived location, browser/device details, page URL, referral data and analytics identifiers under its terms. No Google Analytics JavaScript is loaded until you select Allow analytics on this showcase. Choosing Essential only prevents the script from loading. Global Privacy Control is respected. Click Analytics choices below to revise your choice; accepting or rejecting is stored in browser local storage under cokacremote.showcase.analytics-consent.v1, scoped by the shared host origin but distinguished by its key. Local storage remains until cleared or updated.

If you previously consented, switching to Essential only prevents subsequent tracking from this site's own script on future reloads; browser cookies previously set by Google might require deletion in your browser settings. The shared root-domain blog uses its own independent analytics configuration and may collect according to its policy; this microsite's consent switch does not control analytics on other projects sharing this host.

GitHub Pages & third-party links

This site is served by GitHub Pages, which may process standard hosting request logs. External links to GitHub, Google, Apple and other providers are governed by their own policies. The showcase does not operate its own email or contact database.

Public support issues

Contact and support use public GitHub Issues, not a private form. GitHub may require sign-in, and your issue text, account handle and any attachments will generally be public. Do not submit OAuth keys, API tokens, private endpoints, personal information or internal logs. For GitHub data rights, refer to GitHub's privacy statement.

Contact and removal

To correct or remove content you submitted to a public GitHub issue, use GitHub's issue controls or ask maintainers via the support path. Analytics retention and user controls are managed within Google's services and your browser. Details about Google's processing are at How Google uses information from partner sites.
