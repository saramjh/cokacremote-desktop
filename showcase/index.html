2

On ChatGPT web, open Plugins and add a custom MCP server if your account or workspace permits it.

Enter the endpoint. Review available tools and permissions, then complete OAuth approval in the connection flow.

4

Test a low-risk read-only action first. If the Quick Tunnel hostname changes, update the connection.

Product answers · Search & setup reference

Questions before you connect.

Plain-language answers about the software, platform releases, security and the local MCP connection. These are product facts, not live device diagnostics.

What is cokacremote Desktop Manager?

It is an independent desktop control panel for an upstream local cokacremote MCP server, its Cloudflare Quick Tunnel and OAuth state. It helps you inspect and manage a connection used by ChatGPT; it is not an official OpenAI product.

Does it install the upstream MCP server automatically?

No. The manager does not bundle the upstream server. Dependency inspection and consent-based installation are available in supported flows, but a new computer may still need prerequisites and manual setup.

Can it connect ChatGPT to my computer without my approval?

No. You register the current HTTPS /mcp endpoint in your own ChatGPT account if that feature is available, review permissions and complete OAuth authorization. Do not share approval keys or private tokens.

Which download should I choose for Windows and macOS?

Windows 10/11 currently has a v0.3.0 stable ZIP with a top-level INSTALL.cmd. Apple Silicon Macs have a v0.4.0-rc.2 preview: either an unnotarized DMG or ZIP, or a local-source build that needs Node.js, Rust and Xcode Command Line Tools.

Will changing a Mac DMG to ZIP avoid Gatekeeper?

No. The downloaded macOS preview is not Apple Developer ID notarized. Changing packaging formats does not make the prebuilt app trusted. Use Apple's individual-app approval only if you trust the source; never disable Gatekeeper globally.

Can it still work when my computer is off?

No. The MCP server and Cloudflare tunnel run on your computer. If the device is asleep, powered off or offline, ChatGPT cannot reach that local service. Quick Tunnel URLs can also change when restarted.
